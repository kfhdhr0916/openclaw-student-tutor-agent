# Contributing Guide / 贡献指南

Thank you for your interest in this project.
We welcome contributors from AI, software engineering, and education.

感谢你关注本项目。
欢迎 AI、软件工程与教育方向的开发者共同参与。

---

## Project Goal / 项目目标

Build a coach-style AI tutor that helps students think, debug, and reflect,
instead of directly giving final answers.

构建一个“教练型”AI学习助手，引导学生思考、调试与复盘，
而不是直接给最终答案。

---

## How to Contribute / 如何贡献

### 1) Open an Issue / 提交 Issue
Please describe:
- Problem to solve / 要解决的问题
- Why it matters / 价值与意义
- Proposed approach / 建议方案

请尽量写清楚：
- 要解决什么问题
- 为什么重要
- 你建议怎么做

### 2) Submit a Pull Request / 提交 PR
- Keep PRs small and focused.
- Explain what changed and why.
- Include screenshots or examples when helpful.

- 建议小步提交，单个 PR 聚焦一个主题。
- 说明“改了什么、为什么改”。
- 如有必要，附截图或示例。

## Contribution Rules / 贡献规则

- Do not upload private student data.
- Do not commit secrets (API keys, tokens).
- Follow bilingual style when possible (English + 中文).
- Prefer clarity over complexity.

- 不上传学生隐私数据。
- 不提交任何密钥（API Key、Token 等）。
- 文档尽量中英双语。
- 优先保证可读性与可维护性。

---

## Suggested PR Title Format / 建议 PR 标题

- `feat: ...` new feature
- `fix: ...` bug fix
- `docs: ...` documentation
- `refactor: ...` code cleanup

保持尊重、务实、友善。
一起把重点放在：帮助学生建立 AI 时代的真实能力。
