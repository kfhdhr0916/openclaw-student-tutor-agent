# OpenClaw Student Tutor Agent / OpenClaw 学生编程教练 Agent

A coach-style AI tutor for programming education on OpenClaw.
It guides students to think, test, debug, and reflect — instead of giving direct final answers.

一个基于 OpenClaw 的“教练型”编程学习 Agent。
它的目标不是直接给最终答案，而是引导学生思考、试错、调试和复盘。

---

## Vision / 项目愿景

- Help students build real problem-solving ability in the AI era.
- Turn AI from an "answer machine" into a "thinking coach".

- 帮助学生在 AI 时代建立真正的问题解决能力。
- 把 AI 从“答案机器”变成“思维教练”。

---

## Core Principles / 核心原则

1. **Think first, then ask AI** / 先思考，再问 AI
2. **Hints over full solutions** / 提示优先，不直接给全解
3. **Run, test, and verify** / 必须运行、测试、验证
4. **Reflect after solving** / 每次完成后必须复盘

---

## What This Agent Does / 这个 Agent 做什么

- Clarifies student goals (input/output/constraints)
- Gives step-by-step hints at increasing depth
- Diagnoses errors from runtime logs
- Asks students to explain code in their own words
- Generates short reflection prompts after each task

- 帮学生澄清任务目标（输入/输出/约束）
- 分层给提示（由浅到深）
- 结合运行报错做诊断
- 要求学生用自己的话解释代码
- 每次任务后生成复盘问题

---

## What This Agent Avoids / 这个 Agent 避免什么

- Directly outputting complete final answers by default
- Replacing teacher judgment
- Rewarding copy-paste behavior

- 默认不直接输出完整最终答案
- 不替代老师的教学判断
- 不鼓励复制粘贴式学习

---

## Classroom Use / 课堂使用方式

1. Teacher publishes a task card
2. Student submits initial attempt
3. Agent provides guided hints
4. Student debugs and tests
5. Teacher reviews process + result

1. 老师发布任务卡
2. 学生先提交自己的尝试
3. Agent 给出引导提示
4. 学生调试并完成测试
5. 老师结合过程与结果进行评价
